# Futuristic Signup UI ✨

A modern glassmorphism signup form featuring neon glow effects and a futuristic purple-pink gradient design.

## Features
- Glassmorphism UI
- Neon glow effects
- Modern signup form
- Stylish social login icons

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Getting Started
Clone the repository and open `index.html` in your browser.
